# Prompt Patterns

Use these patterns as concise starting points. Rewrite them to fit the article.

If the user asks in Chinese, prefer writing the final prompt or brief in Chinese too. Do not copy English field labels into a Chinese recommendation unless the user asks for bilingual output.

## Diagram brief pattern

```
Diagram type:
Core message:
Required nodes or stages:
Required labels:
Avoid:
Optional Mermaid starter:
```

Chinese-friendly version:

```
图类型：
核心表达：
必须出现的节点或阶段：
必须出现的标签：
需要避免的内容：
可选 Mermaid 起稿：
```

## Generative illustration prompt pattern

```
Create an editorial illustration for a Chinese tech article about {topic}. Show {scene or metaphor}. Style: {style}. Mood: {mood}. Composition: {composition}. Color direction: {palette}. Keep it clean, readable, and suitable for a blog article. Do not include UI chrome, brand logos, or dense text.
```

Chinese-friendly version:

```
请为一篇中文技术文章绘制编辑感插图，主题是 {topic}。
画面表现 {scene or metaphor}。
风格：{style}。气质：{mood}。
构图：{composition}。色彩方向：{palette}。
整体要干净、易读、适合博客正文，不要出现明显 UI 外壳、品牌 logo 或大段密集文字。
```

Optional negative prompt:

```
Avoid watermark, extra fingers, fake interface text, dense typography, brand logos, cluttered background, low-contrast composition.
```
