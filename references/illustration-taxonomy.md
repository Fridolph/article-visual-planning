# Illustration Taxonomy

Use this reference when a section could map to multiple visual styles.

| Article signal | Best visual class | Why |
| --- | --- | --- |
| Multi-step workflow | Diagram-first | Sequence is clearer than prose alone |
| Tool comparison | Diagram-first or data/reference visualization | Matrix or scorecard is faster to scan |
| Abstract concept or mindset shift | Generative illustration prompt | Supports mood without pretending to be evidence |
| Real product walkthrough | Author-captured evidence | Authenticity matters more than polish |
| Real screenshot but weak focal point | Screenshot enhancement | Clarifies what the reader should notice |
| Metrics, rankings, before/after | Data or reference visualization | Reader needs structured evidence |
| Article header or distribution card | Cover image | Discovery and tone-setting are the main jobs |
| Short concrete section | No illustration needed | Image would add noise |

## Helpful subtypes

### Diagram-first
- Flowchart
- Timeline
- Lifecycle
- Decision tree
- Mind map
- Comparison matrix
- Layered system map

### Data or reference visualization
- Bar chart
- Stat card row
- Pull-quote card
- Checklist card
- Before/after table
- Ranking ladder

### Screenshot enhancement
- Arrow/callout overlay
- Crop-and-zoom inset
- Before/after comparison
- Numbered walkthrough

### Cover image
- Editorial hero illustration
- Topic metaphor image
- Text-safe cover composition

## Selection rules

- Prefer `Diagram-first` when relationships or order matter.
- Prefer `Data or reference visualization` when the section already contains explicit numbers, dimensions, or ranked claims.
- Prefer `Author-captured evidence` when the article's trust comes from a real interface or real artifact.
- Prefer `Screenshot enhancement` when the screenshot exists or should exist, but its key detail still needs guidance.
- Prefer `Generative illustration prompt` only when the image does not need to prove anything factual.
- Prefer `Cover image` when the visual is for the article entry point instead of an in-body explanation.
- Choose `No illustration needed` when the text already lands cleanly without visual help.
